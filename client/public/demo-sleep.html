② 右侧圆形状态徽章 · 轻操作入口

🌙
未记录 — 轻灰底，悬停蓝边，提示操作
😊
有状态 — 微渐变底 + 色描边，颜色统一语义
尺寸 30×30px 圆形，与 checkbox、状态圆点同源
悬停微放大 1.03× + 浅阴影，反馈克制

③ 三行信息结构（仅睡眠有记录时）

第 1 行 主标题：😴 睡眠7小时（14px，与其他习惯一致）
第 2 行 目标信息：23:00 – 06:00 · 目标 7h（12px，浅灰）
第 3 行 实际结果：💤 实际时段+时长 + ✅ 达标 / ⚠ 差XX胶囊
★ 信息唯一：醒后状态不在第三行重复，只在竖条+徽章体现

④ 与工作台全局风格的一致性

✅ 玻璃卡 18px 圆角、半透明白、backdrop-filter
✅ 圆形 checkbox、右侧 8px 状态小点（同源视觉）
✅ 统一字号：14px 主 / 12px 辅，色彩语义一致
✅ 装饰克制：无渐变广告卡、无阴影大盒子、信息零重复

❌ 旧版（当前线上）— 问题清单

  • 信息严重重复：醒后状态同屏出现 3 次（第三行胶囊 + 下方断行 + 右侧彩卡）
  • 排版崩坏：「· 7 小时 · ✅ 达标」中间断行，视觉断裂
  • 装饰过重：渐变卡片 + 两行字 + 阴影，像广告贴纸贴在玻璃卡上
  • 风格不统一：工作台是极简 iOS 风，睡眠行是"电商促销风"
  • 状态识别慢：满屏都是字，扫一眼抓不住"今天醒后怎么样"
  • 行高错乱：睡眠行比其他行高 2 倍多，列表视觉断层

✅ 新版（本 Demo）— 优化点

  • 信息唯一：醒后状态 = 竖条颜色 + 徽章，三行不重复
  • 排版严谨：三行严格对齐，结果标签贴右端，无断行错位
  • 极简克制：取消一切重装饰，状态用"颜色 + emoji"两元素
  • 全局统一：徽章 30px 圆形，和 checkbox / 点同圆系
  • 一眼识别：左侧 3px 色条（左边缘视觉黄金区），0.1 秒感知状态
  • 高度自适应：未记录 = 两行（同其他习惯）；有记录 = 三行（自然升高）
