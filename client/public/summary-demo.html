📌 设计说明（可按需调整绑定粒度）
① 单链接模式：所有天都指向同一份总文档（如在线文档按月分 Tab，当前默认）—— 好处是不用每天新建，只要打开定位到当天 Tab 即可；
② 日模板模式：每天自动生成"当天日期"的新在线文档（通过对应开放接口创建，需要 API 凭证）—— 适合真正独立每日复盘；
③ 双写模式：工作日用在线文档、周末用内置短复盘；或先在工作台写短的，再点"同步到在线文档"自动追加。
