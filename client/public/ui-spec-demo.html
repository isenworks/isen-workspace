核心原则：
1. 颜色 = 身份：事项按"紧急度"分色（红/琥珀/灰），习惯按"成长类型"分色（精力/知力/能力），两套维度互不干扰
2. 习惯面板 + 时间线：都按成长类型分色，习惯卡片颜色一致表达身份
3. 时间线设计：三栏布局（时间标签 · 彩色竖线 · 内容行），06:00–23:00 所有时间点都展示，空时间点用灰色细线
4. 褪色 = 状态：已完成时文字变灰 + 行背景变灰 + 复选框填分类色（饱和度降 20%）+ 竖线变灰，表达"完成但仍保留身份"
5. 小圆点始终保留原色：无论完成与否，事项/习惯右侧小圆点都保留分类色，不褪灰
6. 进度环统一蓝色：表达"完成度"，不与任何分类色混淆
