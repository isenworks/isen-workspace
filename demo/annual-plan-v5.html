设计说明 v5 · 顶尖 UI 视角的年度规划系统

  • 4 种追踪模式： 🔁 习惯打卡 🎯 里程碑 🪞 反思评分 💰 量化目标
  • 反思型目标可衡量：为"认知改变/即兴表达"设置多维度自评卡（输入量、输出量、思维改变、自信度等），每月打分，让"假大空"目标变得可视化
  • 年度视图三件套：KPI 卡片（shimmer扫光效果） + SVG 雷达图（5维平衡） + Q1-Q4 季度轴（当前季度高亮）
  • 5 大领域差异化 UI：精力=习惯热力卡 / 认知=书架+反思卡 / 能力=里程碑时间线+pulse脉冲 / 工作=薪资进度条+阶段卡 / 生活=体验图鉴
  • OKR 层层落地：年度 → 月度主题 → 周计划 → 每日执行卡，自上而下拆解
  • UI 细节：conic品牌标识、玻璃拟态升级、spring悬停弹性、进度条微光扫光、柔和分级阴影
